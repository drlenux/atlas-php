# Проверка нативной архитектуры v0.4

Архитектурная коррекция записана в native-analyzer-design.md до изменения production-кода. Исполнение PHP subprocess заменено прямым вызовом реестра языковых и фреймворковых расширений. Service Layer, доверие, PostgreSQL, MCP и аналитика сохраняют прежние контракты.

## Наблюдаемые red/green

- Первые четыре теста реестра упали на отсутствующем PluginRegistry. После реализации прошли маршрутизация двух языков, независимое обогащение фреймворком, зависимости/неизвестные ID/конфликты расширений и истёкший deadline.
- Новые тесты Config первоначально упали на отсутствующих language_plugins/framework_plugins. После внедрения ENV выбора плагинов и явного отказа устаревшим настройкам все пять config tests прошли.
- Проверка Docker runtime первоначально упала на `runtime still includes php-cli`. После удаления PHP/Composer/Git CLI и вспомогательных tini/curl структурная проверка прошла. Она не заменяет Docker build/run.
- IndexCoordinator получает SourceFile и вызывает реестр напрямую. Тесты проверяют отказ нативного плагина без изменения индекса, общий предел входных данных/графа, синтаксическую ошибку с сохранением trust 3, восстановление кода с обновлением позиции, а также настоящее удаление файла после перезапуска.

## Интеграция

`tests/native_runtime.rs` запускает отдельный тестовый процесс с пустым PATH. В нём действительно отсутствуют `php` и `git`; работают PHP → Yii2 → IndexCoordinator → Service Layer. Повторный анализ с пустым списком framework_plugins сохраняет PHP property_access и не добавляет Yii magic_get. Глобальный PATH остальных тестов не меняется.

`code-atlas plugins` отдельно проверен в процессе без ENV и БД: каталог содержит язык php и фреймворк yii2 с зависимостью php. Новые языки подключаются через тот же trait и регистрацию; им не нужна PHP-специфика индексатора. Общий AnalysisOptions содержит отображение языковых версий, а не поле PHP.

`tests/parser_resilience.rs` проверяет усечения и удаление каждого символа из PHP-примера с Unicode: анализ не паникует и не создаёт висячих рёбер. `tests/workflow.rs` проходит нативный PHP → MCP → правка → переиндексация → approve → аналитика.

Итог: **88 Rust-тестов прошли, 3 PostgreSQL-теста явно пропущены**, 4 JS-теста прошли. Release build, Clippy с запретом предупреждений, rustfmt, Compose config, shell syntax и строгий OpenSpec прошли. Реальный Docker/PostgreSQL/browser запуск остаётся непроверенным из-за ограничений среды; точные границы — в verification.md.
