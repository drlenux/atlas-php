# Нативные расширения анализатора

Уточнение владельца от 4 ноября 2026 отменяет PHP subprocess и Composer. Язык исследуемого проекта не является языком реализации плагина. Поставка содержит PostgreSQL/pgvector и один бинарник Atlas; языковые runtime и Git CLI не требуются приложению.

## Контракт до реализации

- `src/analyzer/`: независимые от языка SourceFile, AnalysisOptions, LanguagePlugin, FrameworkPlugin и реестр. Языковой плагин получает только исходный текст и выдаёт GraphSnapshot. Реестр выбирает файлы по зарегистрированным расширениям. Service Layer и хранилище не зависят от PHP.
- `src/plugins/php/`: встроенный Rust-плагин языка PHP, собственные токены и структурный разбор без исполнения исходников. Сохраняет декларации, области, наследование, вызовы, возвраты, условия и происхождение. Неизвестные/неподдержанные конструкции имеют диагностики; ошибочный файл не разрешает удаление старых данных.
- `src/plugins/yii2/`: отдельный Rust-плагин фреймворка с явной зависимостью от PHP. После базового анализа дополняет граф: свойства getter/setter, behaviors, статические конфигурации компонентов, вызовы Yii::$app. Включается независимо. Неопределённая runtime-конфигурация остаётся неопределённой.
- Плагины регистрируются в составе бинарника при сборке; ENV выбирает включённые плагины. Добавление будущего JS/Go/Rust/Python — реализация LanguagePlugin и регистрация, без переписывания индексатора. Динамический ABI и загрузка сторонних исполняемых файлов не входят в этот этап.
- Индексатор ограниченно читает исходники и вызывает реестр напрямую, затем обогащает Git-данными и транзакционно публикует граф. Лимиты размера, времени и количества элементов проверяются до публикации. Ошибка или превышение лимита сохраняет прежний индекс.
- Git-адаптер читает репозиторий нативно; внешняя команда git допустима только при подготовке тестовых репозиториев. Недоступная или неподдержанная история отражается диагностикой.
- PostgreSQL/libpq остаётся инфраструктурной зависимостью. Runtime Docker не устанавливает PHP, Composer, Node, Python, Go, Rust toolchain или Git. Build stage содержит компилятор.

## Приёмка и TDD

Сначала тесты нового контракта и наблюдаемая красная фаза, затем реализация. Обязательны: анализ без PHP в PATH, независимое выключение Yii2, отказ неизвестному плагину/отсутствующей зависимости, повторная индексация после ошибки без потери защищённых данных, прежние сценарии PHP/Yii и MCP workflow, Git без CLI, структурная проверка Docker. Недоступные Docker/PostgreSQL/browser проверки остаются явно отдельными.

Прежние файлы PHP-плагина удаляются после переноса поведения; PHP-файлы fixtures остаются данными тестов. Исторические отчёты предыдущей версии не являются доказательствами новой реализации.
