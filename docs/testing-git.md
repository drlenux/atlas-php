## Семантика результата

`commit/message` относятся к конкретной запрошенной строке. `after` всегда содержит текущий участок рабочего дерева. `at_commit` отдельно содержит контекст строки в коммите из blame.

`region_commit/region_message` относятся к последнему изменению всего запрошенного участка. Для них используется Git line-history (`log -L`), а не догадка по времени коммитов. Координаты рабочего дерева сначала сопоставляются с HEAD по diff. Если в участке есть незакоммиченные изменения, возвращается `region_uncommitted: true` без выдуманного коммита. Если сопоставление или история недоступны, причина находится в `region_error`.

Добавление и изменение различаются по блокам diff с нулевым контекстом. Чистая вставка не имеет предшествующей строки. Для блока замены `before` показывает предыдущий блок с контекстом; соответствие отдельных строк внутри многострочной замены не угадывается.

## Ограничения

Команды Git запускаются без shell, с отключёнными external diff и textconv там, где они применимы. Вывод каждой команды ограничен 64 MiB и 15 секундами. Кеш команд ограничен 64 MiB и 2048 записями; содержимое и разобранный blame хранятся только для последнего файла. Файл читается с ограничением 16 MiB. Diff в ответе ограничен 400 строками с явной отметкой усечения.

История merge-коммитов с combined diff и отсутствующая история могут возвращать `history_unavailable`; это не доказательство добавления или изменения конкретной строки. Git-проверки не выполняют код исследуемого проекта.
