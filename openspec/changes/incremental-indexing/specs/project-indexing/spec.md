# Project indexing — инкрементальная пересборка

## ADDED Requirements

### Requirement: INDEX-09 Инкрементальная пересборка

После изменения файлов система SHALL заново анализировать тела функций только в изменённых файлах и в файлах, зависящих от изменённых объявлений, и SHALL публиковать только эти файлы. Результат SHALL совпадать с полной пересборкой по объявлениям и связям затронутых файлов. Если зависимых файлов слишком много, а также при первом запуске, по кнопке «Переиндексировать» и после сброса SHALL выполняться полная пересборка.

#### Scenario: Правка тела метода

- **WHEN** меняется только тело метода в одном файле
- **THEN** публикуется только этот файл, а вершины и рёбра других файлов не переписываются

#### Scenario: Новый метод и его вызов

- **WHEN** в класс добавлен метод, а другой, не изменённый файл уже вызывает его по имени
- **THEN** после инкрементальной пересборки вызов в другом файле распознан

#### Scenario: Переименование и удаление

- **WHEN** метод переименован или файл удалён
- **THEN** прежние вершины исчезают, а вызывающие файлы пересобираются

#### Scenario: Наследник

- **WHEN** у родительского класса добавлен метод, а наследник в другом файле его не упоминает
- **THEN** файл наследника пересобирается и получает связь `available_via`
