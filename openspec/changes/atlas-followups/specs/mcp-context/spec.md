# MCP context — вызовы в структуре метода

## ADDED Requirements

### Requirement: MCP-12 Вызовы метода одной строкой

Структура метода через MCP SHALL содержать его исходящие вызовы и постановки в очередь и входящие вызовы, по одной строке на место вызова, со статусом распознавания.

#### Scenario: Что вызывает метод

- **WHEN** агент запрашивает структуру метода с тремя местами вызова, одно из которых ставит задачу в очередь
- **THEN** `calls` содержит три строки, а строка постановки в очередь помечена `⇒` и именем очереди
