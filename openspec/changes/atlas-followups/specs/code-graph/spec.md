# Code graph — публикация фактов анализатора

## ADDED Requirements

### Requirement: GRAPH-10 Актуальные факты анализатора

Публикация SHALL обновлять вершины и рёбра уровня доверия 1, если изменился любой факт анализатора в их metadata, даже если исходный текст не менялся. Диагностики пути, о котором новый анализ сообщил, SHALL заменять прежние диагностики этого пути.

#### Scenario: Новая версия анализатора

- **WHEN** неизменённый код переиндексируется анализатором, который теперь распознаёт вызов
- **THEN** и вершина `call_site`, и ребро `calls` содержат новый `resolution`

#### Scenario: Повторная ошибка разбора

- **WHEN** файл с ошибкой разбора трижды переиндексируется без изменений
- **THEN** его диагностика присутствует один раз

### Requirement: GRAPH-11 Статус места совпадает со статусом эффекта

Вершина места вызова, чтения или записи SHALL иметь тот же `resolution`, что и её ребро эффекта, после анализа языка и после обогащения фреймворками.

#### Scenario: Компонент, распознанный фреймворком

- **WHEN** Yii2 после анализа PHP распознаёт вызов `Yii::$app->mailer->send()`
- **THEN** у вершины `call_site` и у ребра `calls` одинаковый `resolution`
