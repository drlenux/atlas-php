# Atlas runtime — исследование кода в веб-интерфейсе

## ADDED Requirements

### Requirement: RUNTIME-08 Читаемое исследование кода

Веб-интерфейс SHALL показывать места вызова, чтения, записи, возврата и ветки по их выражению и методу-владельцу, а не по техническому идентификатору. Поиск SHALL поддерживать фильтр по виду сущности и подгрузку следующих страниц. Контекст сущности SHALL показываться сгруппированным по вызывающим, владельцу, эффектам и веткам, с условиями пути и переходом к связанной сущности. Полные данные SHALL оставаться доступными по запросу.

#### Scenario: Места записи поля

- **WHEN** проверяющий ищет `dep_tax_control` с фильтром «Записи»
- **THEN** каждый результат показывает выражение записи, метод-владелец и файл со строкой
- **AND** если совпадений больше одной страницы, доступна кнопка подгрузки следующей страницы

#### Scenario: Контекст метода

- **WHEN** проверяющий открывает контекст метода
- **THEN** видны вызывающие методы с выражением вызова и условиями пути
- **AND** видны записи, чтения и вызовы метода с условиями, без сырого JSON по умолчанию
