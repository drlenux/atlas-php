# Происхождение кода по Git

## Purpose

Ранее связывало исследуемый код с последним изменением в Git. По решению владельца (2026-11-05) Git-provenance исключён из продукта: Atlas не читает `.git`, не пишет `metadata.git` и не отдаёт историю коммитов через MCP.

Источник отмены: уточнение владельца после приёмки probe-проекта; исходный раздел 6 ТЗ больше не входит в обязательный объём реализации.

## REMOVED Requirements

### Requirement: GIT-01 Последнее изменение и коммит

Система SHALL NOT предоставлять историю Git, хеш или сообщение коммита как часть данных атласа или MCP-контекста.

#### Scenario: Контекст метода без Git

- **WHEN** агент запрашивает контекст проиндексированного метода
- **THEN** в ответе нет поля `metadata.git` у вершин и возвратов
- **AND** индексатор не выполняет стадию сбора Git-истории

### Requirement: GIT-02 Содержимое до и после правки

Система SHALL NOT включать в граф или MCP-ответ содержимое до/после правки, diff или незакоммиченные изменения из Git.

#### Scenario: Индексация без чтения object store

- **WHEN** выполняется индексация проекта
- **THEN** приложение не открывает `.git/objects`, pack-файлы и не использует Git CLI

### Requirement: GIT-03 Контекст переработанного метода

Система SHALL NOT строить Git-контекст для переработанного метода или участка кода.

#### Scenario: Соседние сущности

- **WHEN** контекст включает связанные вершины метода
- **THEN** у них также отсутствует Git-provenance
